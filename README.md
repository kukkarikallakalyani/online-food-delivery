## 📌 About The Project

Food Express is a modern online food delivery website where users can explore food items, search their favourite dishes, add items to cart, and place orders easily.

The project is designed to provide a simple and user-friendly food ordering experience.

## ✨ Features

- 🏠 Attractive Home Page
- 🍕 Food Menu with 24+ Items
- 🔍 Search Food Items
- 🛒 Add to Cart Functionality
- 💰 Automatic Total Price Calculation
- 📦 Order Confirmation Message
- 🚚 Order Tracking Section
- 🏪 Popular Restaurants Section
- 🔥 Special Offers Section
- ⭐ Customer Reviews
- 📖 About Us Section
- 📞 Contact Us Section
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
